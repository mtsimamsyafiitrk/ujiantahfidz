# Instruksi Proyek: ujiantahfidz

## Alur Kerja Git (WAJIB)

Setiap kali selesai mengerjakan task (setelah commit + push), **langsung** buat PR dan merge tanpa menunggu konfirmasi:

1. Commit perubahan dengan pesan yang jelas
2. Push ke branch yang ditentukan
3. Buat Pull Request ke `main`
4. Merge PR tersebut segera
